# Homepage screenshot

Place your own original in-game screenshot at `assets/images/home-hero.jpg`.

- Recommended size: 1920 × 1080 or larger
- Format: JPG, landscape, no UI if possible
- The site adds a dark gradient automatically so the home-page title stays readable.
- The small placeholder label hides itself as soon as this file exists.

Do not use a screenshot copied from another guide, video, press kit, or game site.
